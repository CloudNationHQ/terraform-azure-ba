# Certificate Example

This example deploys an Azure Batch account with a Batch certificate sourced
from a local `.cer` file.

> **Note:** `azurerm_batch_certificate` is deprecated by the provider because
> the Azure Batch certificates feature was retired on 2024-02-29. For new
> workloads, reference certificates from an Azure Key Vault instead. This
> example is provided for completeness while the resource remains available in
> the `azurerm` v4 provider.
